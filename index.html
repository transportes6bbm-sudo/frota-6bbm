⚙️ Configurações do Gestor

🔐 Banco Online e Login de Usuários

Use este campo para conectar o sistema ao Apps Script publicado. O login validará o nº de Bombeiro e a senha pessoal. O perfil será aplicado a partir da aba USUÁRIOS.

Banco online centralizado: alterações autenticadas são gravadas no Google Sheets e distribuídas aos demais computadores. O armazenamento local funciona apenas como cache/fila temporária.

📋 Instruções de Configuração:

  1. Crie uma planilha no Google Sheets
  2. Acesse Extensões → Apps Script
  3. Cole o código fornecido
  4. Implante como Web App e copie a URL terminada em /exec
  5. Cole a URL no campo Banco Online e Login de Usuários
  6. Cadastre usuários pelo botão Gerenciar Usuários; informe Gmail, CPF e nº de Bombeiro. Senhas ficam em hash no banco, nunca em texto puro
