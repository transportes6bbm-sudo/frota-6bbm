🔐 Banco Online e Login de Usuários

Use este campo para conectar o sistema ao Apps Script publicado. O login validará o usuário na aba USUARIOS e aplicará os perfis GESTOR, OPERADOR ou VISITANTE.

📋 Instruções de Configuração:

  1. Crie uma planilha no Google Sheets
  2. Acesse Extensões → Apps Script
  3. Cole o código fornecido
  4. Implante como Web App e copie a URL terminada em /exec
  5. Cole a URL no campo Banco Online e Login de Usuários
  6. Cadastre os usuários na aba USUARIOS com perfil GESTOR, OPERADOR ou VISITANTE

🔐 Login do Sistema

O login identifica automaticamente quem inclui ou altera lançamentos. Com o banco online ativo, o perfil será consultado na aba USUARIOS da planilha. Sem a URL do Apps Script publicada, o sistema opera em modo local/teste.
